# MorphDrive 3D — Controls Guide

## Viewport Navigation

| Action | Control |
|---|---|
| Rotate the vehicle view | Left-click and drag |
| Pan the view | Right-click and drag |
| Zoom in or out | Mouse wheel |
| Reset the camera | Reset View button |
| Enter or exit fullscreen | Fullscreen button |

## Model Tools

- **Exploded View:** Separates vehicle components visually.
- **Wireframe:** Toggles the wireframe display.
- **Reset View:** Restores the camera position.

## Material and Appearance

The Properties panel provides vehicle appearance controls.

- **Body Color:** Changes the vehicle paint color.
- **Paint Finish:** Selects Glossy, Metallic, or Matte.
- **Metallic:** Adjusts the metallic material value.
- **Roughness:** Adjusts the surface roughness.
- **Restore Original:** Restores the original material appearance.

## Hand Interaction

1. Select Enable Hand Control.
2. Allow webcam access when requested.
3. Place your hand in view of the camera.
4. Use the tracked hand to interact with vehicle parts.

The hand tracking and orientation indicators display current tracking information.

Hand interaction is experimental and requires a working webcam and camera permission.

## Notes

Camera access generally requires localhost or HTTPS.
